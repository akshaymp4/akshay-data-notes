    Cloud Computing Introduction

    Cloud computing means using servers, storage, databases, networking, analytics, and machine learning services over the internet instead of owning physical hardware.

    1.1 What Is Cloud Computing?¶

    Cloud computing allows you to rent technology services when you need them.

    Instead of buying and maintaining your own servers, you can use services from cloud providers such as AWS, Azure, and GCP.

    Simple example:

    • Traditional way: buy a server, install software, maintain hardware, and scale manually
    • Cloud way: create a virtual server or storage service online and pay only for what you use

    1.2 Why Cloud Is Useful¶

    Cloud is useful because it makes technology easier to start, scale, and manage.

    Main benefits:

    • No need to buy physical servers
    • Easy to increase or decrease resources
    • Pay based on usage
    • Access services from anywhere
    • Built-in security and monitoring tools
    • Many ready-made services for data, analytics, and machine learning

    1.3 Three Major Cloud Providers¶

    Simple difference between AWS, Azure, and GCP

    Cloud Provider Full Name Simple Understanding Common Strength
    AWS Amazon Web Services Very popular cloud platform with a large number of services Broad cloud services and data engineering tools
    Azure Microsoft Azure Microsoft cloud platform that works well with Microsoft tools Enterprise systems, Power BI, SQL Server, and Microsoft integration
    GCP Google Cloud Platform Google cloud platform known for analytics and data services BigQuery, data analytics, and machine learning

    1.4 Easy Comparison¶

    Need AWS Example Azure Example GCP Example
    Store files S3 Blob Storage Cloud Storage
    Run a server EC2 Virtual Machines Compute Engine
    Run code without servers Lambda Azure Functions Cloud Functions
    SQL database RDS Azure SQL Database Cloud SQL
    Data warehouse Redshift Synapse Analytics BigQuery
    Data pipeline Glue Data Factory Dataflow
    Machine learning SageMaker Azure Machine Learning Vertex AI
    Identity and access IAM Entra ID and RBAC IAM

    1.5 Which Cloud Should You Learn?¶

    There is no single best cloud for everyone.

    For beginners, the goal is to understand common cloud ideas first:

    • Storage
    • Compute
    • Databases
    • Networking
    • Security
    • Data pipelines
    • Analytics
    • Machine learning

    Once these ideas are clear, learning AWS, Azure, or GCP becomes easier because many services solve similar problems with different names.

    1.6 Quick Summary¶

    • Cloud means renting technology services over the internet
    • AWS, Azure, and GCP are the three major cloud platforms
    • All three provide storage, compute, databases, networking, analytics, and machine learning services
    • AWS is widely used and has many services
    • Azure is strong in Microsoft-based company environments
    • GCP is strong in analytics, BigQuery, and machine learning workflows
